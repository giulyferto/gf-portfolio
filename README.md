# Giuliana Fertonani — Portfolio

Personal portfolio site. Next.js (App Router) + TypeScript + Tailwind CSS v4,
with a React Three Fiber hero (tennis balls that assemble into a name, then
disperse into an ambient, mouse-reactive field) and EN/ES language switching
via `next-intl`.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000 — it redirects to `/en` (or `/es`, based on your
browser's language) automatically.

## Adding your projects

Everything project-related lives in one place: `src/data/projects.ts`. Each
entry is a `Project` object — see the `example-project` entry already in
there for the exact shape, then delete it once you've added your own.

A few things worth knowing about that shape:

- Text fields (`role`, `summary`, `description`) are `{ en, es }` objects —
  fill in both languages.
- `githubUrl` is optional. Set it for public projects; leave it out entirely
  for private/proprietary ones. Everything else about a project (photos,
  videos, description, tech stack, your role) works identically either way —
  the only difference is whether a code link renders on the card.
- `media` items reference files under `public/media/<project-slug>/...` —
  drop images/videos there and point `src` at them (e.g.
  `/media/my-app/hero.png`).

## Translations

- UI copy (nav labels, section headings, buttons) lives in `messages/en.json`
  and `messages/es.json`.
- `about.body` and `footer.body` in both files are still TODO placeholders —
  that's your bio and contact info to write.
- To add a third language: add the locale to `src/i18n/routing.ts`, then add
  a matching `messages/<locale>.json`.

## Years of experience

The "5+ years of experience" figure in the hero isn't hardcoded — it's
computed from `CAREER_START_DATE` in `src/lib/experience.ts` (currently set
to 2021-06-01), so it advances on its own every year without you touching
the copy again.

## Project structure

```
src/
  app/[locale]/       route segment for both languages (layout, home page)
  components/         Nav, Hero (+ TennisBallField/HeroCanvas), About,
                       ProjectsSection/ProjectCard, Footer, LocaleSwitcher
  data/projects.ts    all project content — start here
  i18n/                next-intl routing/navigation/request config
  lib/experience.ts   years-of-experience calculation
messages/              en.json / es.json UI strings
public/media/          project images and videos (create as needed)
```

## Deploying

This is set up to deploy on [Vercel](https://vercel.com/new) with zero
configuration — connect this GitHub repo and push. Every push to `main`
redeploys automatically.

## A note on `AGENTS.md` / `CLAUDE.md`

These two files are auto-generated by Next.js itself (16+) to brief AI
coding assistants on breaking changes since their training data — not
something added by hand. `next dev`/`next build` re-create them if removed,
so they're left in place and committed, per Next's own guidance in the file.
